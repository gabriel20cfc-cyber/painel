Privacy policy

Last updated: October 26, 2026

What the app is

Painel dos canais is a personal dashboard that runs only on its owner's computer. It shows statistics of the owner's own YouTube channels.

What data it uses

  • Channel and video information and statistics from the YouTube Data API (read-only).
  • Channel and video metrics from the YouTube Analytics API (read-only).

How the data is used and stored

  • The data is used only to display the dashboard to the channel owner.
  • Access tokens and the downloaded statistics are stored only on the owner's computer. Nothing is sent to any server other than Google's own APIs.
  • The data is never sold, shared, or used for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app from the computer deletes all stored data.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube Terms of Service and the Google Privacy Policy.
